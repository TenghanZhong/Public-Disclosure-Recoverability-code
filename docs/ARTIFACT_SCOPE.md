# Artifact Scope

Included:

- code for mandate-proxy bounds, candidate menus, feature construction,
  revealed-preference scoring, and benchmark evaluation;
- pipeline and analysis scripts;
- configuration files;
- compact summary tables and figures;
- synthetic-data and validation tests.

Excluded:

- raw regulatory filings;
- large row-level parquet outputs;
- machine-specific paths;
- cached bytecode and test-cache directories;
- typesetting build files.

Full data runs require the disclosure inputs described in `docs/DATA.md`.

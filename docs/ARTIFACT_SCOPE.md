# Artifact Scope

Included:

- core package code for mandate-proxy bounds, candidate menus, feature
  construction, revealed-preference scoring, and benchmark evaluation;
- pipeline and analysis scripts;
- configuration files;
- compact reported tables and figures;
- synthetic-data and validation tests.

Excluded:

- raw regulatory filings;
- large row-level parquet outputs;
- machine-specific paths;
- cached bytecode and test-cache directories;
- typesetting build files.

The repository is a compact code and evidence package. Full data
reruns require the disclosure inputs described in `docs/DATA.md`.

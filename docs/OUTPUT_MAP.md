The reported supervised implementation is
`scripts/pipeline/run_supervised_ranker_f20.py`. It retains a 20%
recommendation set, not a top-1 prediction. A full-data run writes
`outputs/supervised_ranker/supervised_ranker_f20_row_level.parquet`.
The compact reported table is regenerated by
`scripts/analysis/build_supervised_f20_reported_table.py`.
The older `run_blackbox_ranker_baseline.py` is retained only as a top-1
diagnostic and is not the source of the supervised rows reported in the paper.

Full-data diagnostics write the holdings-count exclusion check to
`tables/mechanical_robustness/reported_mechanical_robustness.csv` and the
buy-and-hold adjusted drift check to
`tables/candidate_drift_diagnostics/buyhold_adjusted_asset_drift_regressions.csv`.

The figure builder records its source table list in
`figures/figure_manifest.json` when it is run.
